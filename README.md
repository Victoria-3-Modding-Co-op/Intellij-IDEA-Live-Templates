### Importing Live Templates
**Share live templates** page on the IDEA website: https://www.jetbrains.com/help/idea/sharing-live-templates.html

IntelliJ IDEA stores definitions of custom live template groups and templates added to predefined template groups in automatically generated XML configuration files.

**Follow these steps to import these Live Templates to IDEA:**
1. Select File | Manage IDE Settings | Import Settings from the menu.
2. Specify the path to the archive with the exported live templates.
3. In the Select Components to Import dialog, select the Live templates checkbox and click OK.
